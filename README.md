# ⚔️ 세미온 디펜스 🔮

직업을 고르고, 친구와 시너지를 맞춰 30웨이브를 막아내는 **협동 멀티플레이 타워 디펜스** 웹 게임입니다.
(1~4인, 브라우저에서 바로 플레이)

## 로컬 실행

```bash
npm install
npm start
```

브라우저에서 http://localhost:3000 접속 → 닉네임 입력 → **방 만들기** → 초대 링크를 친구에게 보내기.

테스트용 배속: `SIM_SPEED=5 npm start` (게임이 5배 빠르게 진행)

## Render 배포

1. 이 폴더를 GitHub 저장소에 올립니다.
2. Render → **New → Web Service** → 저장소 선택
3. 설정
   - Build Command: `npm install`
   - Start Command: `npm start`
4. 배포가 끝나면 `https://<이름>.onrender.com` 으로 접속

> 무료 플랜은 15분간 접속이 없으면 잠들어서 첫 접속이 30초~1분 걸릴 수 있어요.

## 조작

| 입력 | 동작 |
|---|---|
| 1~4 | 타워 선택 (4번은 궁극기, 10웨이브 클리어 후 해금) |
| 좌클릭 | 설치 / 타워 선택 |
| 우클릭 | 맵에 핑 (설치 중이면 취소) |
| R | 웨이브 준비 (전원 준비 시 즉시 시작) |
| U / S | 선택한 내 타워 업그레이드 / 판매 |
| Enter | 채팅 |
| Esc | 선택 취소 |

설치할 타워를 고르고 맵 위에 마우스를 올리면 **여기 지으면 발동될 시너지**가 미리 보입니다.

## 게임 규칙

- **직업 4종** (중복 불가): 전사 / 마법사 / 궁수 / 사제. 직업마다 전용 타워 4종 + 패시브
- **태그 시너지**: 팀 전체 타워의 태그(물리·화염·냉기·번개·신성·치명타·지원·광역) 개수가 2/4/6개가 되면 발동
- **조합 시너지**: 서로 다른 직업의 타워가 2.5칸 안에 붙어 있으면 발동 (예: 냉기 타워 옆 전사 타워 = 산산조각)
- 골드는 개인, 생명력은 팀 공유. 막타 친 사람이 처치 골드, 웨이브 보너스는 전원
- 5웨이브마다 보스 (재생 / 소환 / 무적 / 질풍)
- 연결이 끊겨도 **같은 방 코드 + 같은 닉네임**으로 다시 들어오면 이어서 플레이

## 파일 구조

```
server.js          서버 (방, 로비, 게임 시뮬레이션, 시너지 계산)
shared/config.js   ★ 모든 수치/데이터 (직업, 타워, 태그, 시너지, 적, 웨이브)
public/index.html  화면 구조
public/game.js     클라이언트 (그리기, 입력, UI)
public/statues.js  타워 석상 그래픽
public/style.css   스타일
```

## 밸런스 조정 / 콘텐츠 추가

전부 `shared/config.js` 한 파일에서 합니다.

- **타워 수치**: `TOWERS` 의 `dmg`, `rate`, `range`, `cost` 등
- **새 조합 시너지**: `COMBOS` 배열에 항목 추가
  ```js
  { id: 'my_combo', name: '새 조합', icon: '🔥',
    a: { cls: 'mage' }, b: { tag: 'physical' }, target: 'b',
    desc: '설명', effect: { dmgMult: 1.3 } }
  ```
  `effect` 규칙: 이름이 `...Mult` 로 끝나면 곱하기, 숫자는 더하기, `true` 는 켜기
- **적 체력 난이도**: `hpScale` (웨이브당 배율), `playerHpFactor` (인원별 배율)
- **웨이브 구성**: `makeWave(w)`
- **석상 모양**: `public/statues.js` 의 `STATUES` 에서 타워별로 그리는 함수 수정
